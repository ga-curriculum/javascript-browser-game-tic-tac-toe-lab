# ![JavaScript Browser Game - Tic-Tac-Toe Lab](./assets/hero.png)

## About

In this lab students build a Tic-Tac-Toe game that incorporates the technologies and practices they've learned so far:

- HTML
- CSS
- JavaScript
- DOM manipulation

## Prerequisites

- Foundational knowledge of HTML, CSS, and JavaScript
- Intro to the DOM
- DOM Events

## Time to complete

Estimated time to complete core lab exercise: **8 hrs**
